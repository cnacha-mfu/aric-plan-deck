## การใช้งาน

`←` / `→` เลื่อนสไลด์ · `R` เล่นแอนิเมชันของสไลด์ปัจจุบันซ้ำ · `G` ดูภาพรวมทั้งหมด ·
คลิกจุดด้านล่างเพื่อข้ามไปสไลด์ที่ต้องการ

แต่ละสไลด์มีแอนิเมชันเปิดตัวเมื่อแสดง (ผู้ที่ตั้งค่าลดการเคลื่อนไหวจะเห็นเพียงการค่อย ๆ ปรากฏ)
เนื้อหาแสดงครบโดยไม่ต้องรอแอนิเมชัน จึงพิมพ์เป็น PDF ได้ตามปกติ

หน้าเดียวจบ ไม่มี build step — แก้ `index.html` แล้ว push ได้เลย
**เพิ่มค่า `<meta name="deck-version">` ทุกครั้งที่เผยแพร่** เพื่อให้เบราว์เซอร์ที่เก็บสำเนาเก่าโหลดใหม่เอง
