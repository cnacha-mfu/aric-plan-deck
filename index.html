MFii ต่อยอดสิ่งที่วิจัยเสร็จแล้ว · ARIC สร้างสิ่งที่ยังไม่มีจากโจทย์ของผู้ใช้ — สองกลไกส่งงานต่อกัน ไม่ได้แย่งงานกัน

เครื่องมือคุ้มครองและถ่ายทอดทรัพย์สินทางปัญญาDGX · AI coding agent และ tech PM ประกบทีมรายวัน
ผลตอบแทนค่าอนุญาตใช้สิทธิใน IP ของมหาวิทยาลัยหุ้น 15% ผ่านมูลนิธิ — ทีมส่วนใหญ่มาจากภายนอก ไม่มี IP ของมหาวิทยาลัยให้อนุญาตใช้สิทธิ
